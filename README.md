# STALCRAFT-MODS - Модификации для STALCRAFT

**STALCRAFT-MODS** - набор модификаций для игры STALCRAFT, включая локализации, переводы по лору и обёртки для кастомных конфигов.

Это коллекция пользовательских модов, созданных для расширения и улучшения игры STALCRAFT.

[![Status](https://img.shields.io/badge/Status-Active-brightgreen.svg)]()

## 🎯 Цели проекта

- Предоставить качественные модификации для STALCRAFT
- Сохранить оригинальную атмосферу S.T.A.L.K.E.R. в игре
- Создать удобную базу для сообщества мододелов

## 📁 Архитектура

```plaintext
├── wrapper/                 # Обёртка для кастомных конфигов
│   ├── configs/             # Конфигурации обёртки
│   │   ├── default.json     # Конфиг по умолчанию
│   │   └── hight.json       # Продвинутая конфигурация
│   └── examples/            # Примеры использования
│       └── 8khz.json        # Пример конфигурации
├── config/                  # Основные конфиги модов
│   ├── options.json         # Настройки модификаций
│   └── waypoints.cfg        # Вейпоинты
├── radio/                   # Мод радиопереговоров
├── LICENSE                  # MIT License
└── README.md                # Документация по установке и использованию
```

## 📋 Быстрый старт

### Установка модов

1. Скачайте архив с модами
2. Скопируйте содержимое в папку с игрой STALCRAFT
3. Запустите игру

> 📌 Для каждой модификации есть отдельная инструкция в папке мода.
